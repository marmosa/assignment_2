# FK Bodø/Glimt - Player Cards

## Project Description

I made this website as part of Assignment 2 in my Full-Stack Development course.

The website is about FK Bodø/Glimt, a Norwegian football club.

It includes 15 player cards with pictures and information about each player, such as their name, shirt number, position and nationality.

I used HTML and CSS to build the website. I also used CSS Grid to make the player cards adjust to different screen sizes.

## Technologies Used

HTML5 for the content and structure.

CSS3 for styling the website.

CSS Grid to organize the player cards.

CSS variables to keep the colors consistent.

BEM naming convention for CSS classes.

Google Fonts (Oswald) for headings and player names.

## Responsive Design

I wanted the website to work on computers, tablets and mobile phones.

I used CSS Grid so the number of player cards in each row changes depending on the screen size.

## Image Usage and Copyright

My original plan was to make a website with 15 players from the current FK Bodø/Glimt team.

I contacted the club to ask if I could use pictures from their website for my school assignment, but they said no.

Because of this, I had to find pictures from other sources. I found pictures on Wikimedia Commons that I could use with Creative Commons licenses.

I couldn't find pictures of all the current players, so I decided to include some former Bodø/Glimt players as well.

This way, I could have a picture of every player without using images I didn't have permission to use.

The image sources, photographers and licenses are listed below.
